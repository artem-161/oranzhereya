# 🌿 Оранжерея

Личный дневник растений для iPhone: коллекция, трекер полива и ухода, хотелки.
Это PWA: открывается в Safari, ставится на экран «Домой» и дальше работает как обычное приложение, в том числе без интернета.

**Сервера нет.** Все данные хранятся только на телефоне, в браузерном хранилище (IndexedDB).

## Что внутри

| Вкладка | Что делает |
|---|---|
| **Сегодня** | Приветствие, кольцо прогресса дня, полоска недели, что полить или подкормить сейчас и в ближайшие 7 дней. Отметка одним тапом, с отменой. |
| **Коллекция** | Сетка растений с фото, поиск, фильтр по комнатам, бейдж «пора полить». |
| **Карточка растения** | Фото, освещение, сколько живёт дома, быстрые действия (полить, подкормить, опрыскать, пересадить, обрезать), расписание с прогресс-барами, дневник ухода, заметки. |
| **Хотелки** | Список желаний: приоритет-сердечки, цена, где купить, ссылка, фото-референс. Кнопка «Уже моё!» переносит растение в коллекцию. |
| **Ещё** | Имя, статистика, инструкция по установке, резервная копия (экспорт и импорт .json), примеры, сброс. |

Круглая кнопка `+` рядом с меню сама понимает контекст: в коллекции добавляет растение, в хотелках добавляет хотелку, в карточке растения создаёт запись в дневнике.

## Запуск на компьютере

```bash
python3 -m http.server 5291
```

Потом открыть http://localhost:5291. Сборка не нужна: обычные HTML, CSS и JS-модули.

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub, например `oranzhereya`, и залить туда содержимое этой папки:
   ```bash
   git init && git add . && git commit -m "Оранжерея: первая версия"
   git branch -M main
   git remote add origin https://github.com/<логин>/oranzhereya.git
   git push -u origin main
   ```
2. На GitHub: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** → Save.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/oranzhereya/`.

## Установка на iPhone (для Юли)

1. Открыть ссылку в **Safari** (именно в Safari).
2. «Поделиться» → **«На экран „Домой“»** → «Добавить».
3. Запускать с иконки. Так приложение открывается на весь экран, работает офлайн, а iOS бережнее хранит его данные.

> ⚠️ Данные живут только в этом приложении на этом телефоне. Если удалить иконку с экрана «Домой» или очистить данные Safari, они пропадут. Поэтому раз в месяц стоит делать **Ещё → Сохранить резервную копию** и отправлять файл себе в «Файлы» или в Telegram.

## Устройство кода

```
index.html            оболочка: фон, стеклянный таббар, кнопка +, точки монтирования
manifest.webmanifest  PWA-манифест (имя, иконки, цвета)
sw.js                 service worker: офлайн-кэш
css/styles.css        вся тема; цвета в :root, есть тёмная тема
icons/                иконка приложения (svg и png)
js/
  app.js              роутер (#/today, #/plants, #/plant/:id, #/wishes, #/more) и все действия
  store.js            данные: схема, сохранение в IndexedDB, расчёт сроков ухода, демо, бэкап
  forms.js            шторки-формы: растение, хотелка, запись ухода
  ui.js               тосты, нижние шторки, подтверждения, сжатие фото
  icons.js            набор линейных SVG-иконок
  dates.js            даты по-русски («через 3 дня», «2 года 3 мес.»)
  views/*.js          экраны; каждый экспортирует render() → { title, html, mount? }
```

### Как дорабатывать

- **Новый вид ухода** (например, «протереть листья»): добавить строку в `CARE` в `js/store.js` и, если нужно, иконку в `js/icons.js`. Формы, кнопки и расписание подхватят его сами.
- **Новый экран**: создать `js/views/имя.js` с `render()`, добавить маршрут в `routes` в `js/app.js` и, если нужно, вкладку в `index.html`.
- **Новое поле у растения**: добавить его в форму в `js/forms.js` и значение по умолчанию в `normalizePlant()` в `js/store.js`. Старые данные получат значение по умолчанию автоматически.
- **Изменился формат данных**: увеличить `SCHEMA` и дописать шаг в `migrate()` в `js/store.js`, чтобы у Юли ничего не сломалось.
- **Цвета и стекло**: переменные в начале `css/styles.css`, стекло описано в блоке `LIQUID GLASS`.
- **После изменений** service worker сам подтянет новые файлы при следующем открытии с интернетом. Если добавлен новый файл, его нужно вписать в `SHELL` в `sw.js` и увеличить `VERSION`.

## Идеи на будущее

- Напоминания. iOS не умеет локальные уведомления в PWA по расписанию, для пушей нужен сервер. Вариант без сервера: кнопка «Добавить в Календарь» (.ics с повтором).
- Фото-таймлайн роста растения.
- Статистика полива за месяц.
- Справочник по видам с рекомендациями по уходу.
- Синхронизация через iCloud Drive (сохранение бэкапа одним тапом).
